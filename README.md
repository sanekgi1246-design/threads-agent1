# Threads-агент для крипто-канала

Агент работает бесплатно на GitHub Actions и делает три вещи:

1. **Пишет и публикует посты в Threads** по официальному API, 3 раза в день, на полном автопилоте.
2. **Собирает метрики** каждые 3 часа и показывает их на дашборде (GitHub Pages).
3. **Ведёт трафик в Telegram.** Каждый 3-й пост получает комментарий-ответ с **отдельной ссылкой-приглашением**, поэтому видно, какой пост сколько людей привёл в канал.

## Как он думает

```
выбор рубрики ──► реальные данные ──► нейросеть пишет ──► проверка ──► публикация ──► метрики
   ▲  (по метрикам)  (CoinGecko, индекс     (Groq, бесплатно)  (длина, запрет.     (+ ответ со          │
   │                  страха, RSS новостей)                     фразы, повторы)     ссылкой в TG)       │
   └───────────────────────────────────── вовлечённость по рубрикам ◄─────────────────────────────────┘
```

* **Самообучение.** Сначала агент пробует каждую рубрику минимум 3 раза. Дальше в 70% случаев берёт рубрику с лучшей вовлечённостью, в 30% пробует другие. Лучшие посты он получает как образец стиля.
* **Защита от вранья и «финсоветов».** Цифры он берёт только из реальных источников. Прогнозы и призывы «купить» запрещены, есть стоп-лист фраз, а пост, похожий на недавние, он переписывает.
* **Ссылка не в самом посте, а в ответе.** Так основной пост не теряет охват.

Рубрики, голос, частоту ссылок и стоп-слова меняй в **`config.yaml`**.

## Настройка (≈30 минут, один раз)

### 1. Репозиторий
1. Создай на GitHub **публичный** репозиторий. Для публичных репозиториев Actions и Pages бесплатны.
2. Загрузи все файлы (*Add file → Upload files*). Файлы `post.yml`, `metrics.yml`, `refresh-token.yml` должны лежать в `.github/workflows/`.
3. **Settings → Pages** → Source: *Deploy from a branch* → Branch `main`, папка `/ (root)`. Дашборд будет по адресу `https://<ник>.github.io/<репо>/`.

> В `data.json` хранятся тексты постов и цифры. Они и так публичны в Threads. Ключи и токены лежат только в Secrets и в репозиторий не попадают.

### 2. Токен Threads
1. Зайди на [developers.facebook.com](https://developers.facebook.com/apps) → **Create App** → сценарий **«Access the Threads API»**.
2. В приложении: **Use cases → Customize → Permissions**, включи `threads_basic`, `threads_content_publish`, `threads_manage_insights`, `threads_read_replies`.
3. **App roles → Roles → Add Threads Tester** → твой аккаунт Threads. Затем в приложении Threads: *Настройки → Аккаунт → Разрешения сайтов → Приглашения* → принять.
   *Для своего аккаунта в режиме тестера App Review не нужен.*
4. **Use cases → Settings → User Token Generator** → *Generate access token*. Получишь короткий токен (живёт 1 час).
5. Обменяй его на долгий токен (60 дней). Вставь в браузер:
   ```
   https://graph.threads.net/access_token?grant_type=th_exchange_token&client_secret=<APP_SECRET>&access_token=<КОРОТКИЙ_ТОКЕН>
   ```
   `APP_SECRET` лежит в *App settings → Basic → Threads app secret*. Из ответа возьми `access_token`.
6. Узнай свой ID: `https://graph.threads.net/v1.0/me?access_token=<ДОЛГИЙ_ТОКЕН>` → поле `id`.

### 3. Бесплатная нейросеть (Groq)
[console.groq.com](https://console.groq.com) → API Keys → Create. Карта не нужна.
*Можно подключить любую другую модель с OpenAI-совместимым API: OpenRouter, Gemini и т.д. В **Settings → Secrets and variables → Actions → Variables** задай `LLM_BASE_URL` и `LLM_MODEL`.*

### 4. Telegram-бот (для учёта переходов)
1. У [@BotFather](https://t.me/BotFather) создай бота и возьми токен.
2. Добавь бота **администратором канала** с правом *«Приглашение пользователей по ссылке»*.
3. ID канала: `@имя_канала` (для публичного) или `-100…` (для приватного).
4. *(необязательно)* Свой chat id для уведомлений: напиши боту [@userinfobot](https://t.me/userinfobot). Агент будет присылать тебе каждый опубликованный пост и ошибки.
5. В `config.yaml` впиши `channel_url`. Эта ссылка используется, если бот недоступен.

### 5. Секреты
**Settings → Secrets and variables → Actions → New repository secret:**

| Секрет | Что это |
|---|---|
| `THREADS_ACCESS_TOKEN` | долгий токен из шага 2.5 |
| `THREADS_USER_ID` | id из шага 2.6 |
| `LLM_API_KEY` | ключ Groq |
| `TG_BOT_TOKEN` | токен бота |
| `TG_CHANNEL_ID` | `@канал` или `-100…` |
| `TG_ADMIN_CHAT_ID` | твой chat id (необязательно) |
| `GH_PAT` | [Fine-grained token](https://github.com/settings/personal-access-tokens/new) только на этот репозиторий, право **Secrets: Read and write**. Нужен, чтобы агент сам продлевал токен Threads |

### 6. Первый запуск
1. **Actions → «Публикация поста» → Run workflow → поставь галочку «Только показать текст».** В логе появится пост, который агент написал бы. Если стиль не нравится, поправь `voice` и рубрики в `config.yaml`.
2. Запусти ещё раз без галочки: пост уйдёт в Threads.
3. **Actions → «Сбор метрик» → Run workflow**, затем открой дашборд.

Дальше всё идёт само: посты выходят в ~9, ~14 и ~19 по Киеву (±15 минут), метрики собираются каждые 3 часа, токен продлевается дважды в месяц.

## Что стоит знать
* **Лимиты Threads:** 250 постов и 1000 ответов за 24 часа. Агенту хватает с огромным запасом.
* **Расписание GitHub неточное:** запуск может опоздать на 5–30 минут. Для соцсетей это не критично.
* GitHub отключает расписание в репозитории **без активности 60 дней**. Агент коммитит каждые 3 часа, так что это не случится. Если отключит, просто нажми *Enable workflow*.
* **«Пришли в TG»** считает только тех, кто вступил по персональной ссылке из поста. Общий прирост канала виден на графике участников.
* **Время публикации:** cron в `.github/workflows/post.yml` задан в UTC. Летом по Киеву посты будут выходить на час позже. Если нужно, поправь.
* Если Groq убрал модель, агент сам переключится на запасную. Свою модель можно задать в переменной `LLM_MODEL` (можно списком через запятую).

## Структура
```
config.yaml                 ← всё, что можно настраивать
post.py                     ← выбор рубрики, генерация, проверки, публикация
metrics.py                  ← метрики Threads + вступления в Telegram
threads_api.py              ← клиент официального Threads API
llm.py                      ← любая OpenAI-совместимая нейросеть
sources.py                  ← цены, индекс страха и жадности, новости из RSS
telegram.py                 ← ссылки-приглашения, счётчик, уведомления
common.py                   ← конфиг и хранилище
index.html                  ← дашборд
data.json                   ← состояние (ведёт агент)
.github/workflows/*.yml     ← расписание
```
